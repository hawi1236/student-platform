# Student Resource Sharing Platform

## Description

This is a full-stack web application that allows students to upload, share, and download academic materials, and participate in Q&A discussions.

## Technologies Used

* Frontend: React
* Backend: Node.js, Express
* Database: MongoDB Atlas

## Features

* User authentication (login/register)
* Upload and download materials
* Q&A system
* Search functionality

## How to Run

### Backend

```bash
cd server
npm install
node server.js
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
